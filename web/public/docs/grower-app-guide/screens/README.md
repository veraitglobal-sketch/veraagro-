# Snimci ekrana — uputstvo za mobilnu aplikaciju

## Gde su fajlovi

Stavite slike u **roditeljski folder** (ne u `screens/`):

`web/public/docs/grower-app-guide/`

Stranica: **`/grower/app-guide`**

## Trenutna imena (kako ste dodali)

| Fajl | Ekran |
|------|--------|
| `1.PNG` | Welcome |
| `2.PNG` | Registracija |
| `3.PNG` | Prijava |
| `4.PNG` | Početna (home) |
| `5.PNG` | Polje (field tab) |
| `6.jpeg` | Lotovi |
| `7.jpeg` | Snabdevači |
| `8.jpeg` | Profil |
| `9.jpeg` | Novčanik |

Ekstenzija mora tačno da odgovara (`.PNG` vs `.jpeg`). Na Linux/Vercel serveru velika/mala slova su bitna.

## PDF

1. Otvorite `/grower/app-guide` ulogovani kao proizvođač.
2. **Štampaj → Sačuvaj kao PDF** → `biovera-grower-app-uputstvo.pdf` u isti folder.
